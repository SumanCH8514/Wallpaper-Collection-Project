Developer API Documentation
1. Random Wallpaper API

Fetches a random high-resolution wallpaper. Redirects directly to the image or returns structured JSON metadata.

GET https://wallpapers.sumanonline.com/api/random?json=true
2. Edge-Cached Image Proxy

Stream any wallpaper with permanent 1-year browser and Edge CDN cache headers.

GET https://wallpapers.sumanonline.com/api/images/:filename
3. Paginated Catalog API

Query the full collection of 337 wallpapers with tag filtering, search queries, and pagination.

GET https://wallpapers.sumanonline.com/api/wallpapers?tag=mountain&limit=40
